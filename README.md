# Portfolio — Sajith Jeewantha

Source for [sajithjeewantha.com](https://sajithjeewantha.com): a static portfolio, blog and [career roadmaps](https://sajithjeewantha.com/roadmaps/) built with **Astro** and **Tailwind CSS** (current version: **v1.2.0**).

The app lives in [`site/`](site/).

```sh
cd site
npm install
npm run dev      # http://localhost:4321
```

See **[site/README.md](site/README.md)** for all commands, how to edit content (JSON and Markdown, including the roadmaps), the design system, themes and deployment.

> The previous version (v0: Django + PostgreSQL on Supabase, deployed to Cloud Run with Terraform) is preserved in the git history before the `v1.0.0` release.
