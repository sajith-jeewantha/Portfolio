# Portfolio — Sajith Jeewantha

Source for [sajithjeewantha.com](https://sajithjeewantha.com): a static portfolio and blog built with **Astro** and **Tailwind CSS**.

The app lives in [`site/`](site/).

```sh
cd site
npm install
npm run dev      # http://localhost:4321
```

See **[site/README.md](site/README.md)** for all commands, how to edit content (JSON and Markdown), the design system, themes and deployment.

> The previous version (v0: Django + PostgreSQL on Supabase, deployed to Cloud Run with Terraform) is preserved in the git history before the `v1.0.0` release.
